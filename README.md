🚢 Titanic Dashboard – Tableau

📌 Project Overview

This project presents an interactive Titanic Data Analysis Dashboard created using Tableau. The dashboard analyzes passenger information from the Titanic dataset and provides meaningful insights into survival patterns, passenger demographics, gender, age, class, and other factors.

The main objective of this project is to transform raw Titanic data into an interactive and easy-to-understand visual dashboard.


🎯 Objectives

- Analyze the survival rate of Titanic passengers.
- Compare survival based on gender and passenger class.
- Understand passenger demographics such as age and class.
- Identify patterns among survived and non-survived passengers.
- Create interactive visualizations using Tableau.
- Present data-driven insights in a simple and visually appealing format.

🛠️ Tools & Technologies

- Tableau – Data visualization and dashboard creation
- Microsoft Excel / CSV – Dataset and data preparation
- Data Analysis – Exploratory analysis and visualization

📊 Dashboard Features

The dashboard includes visualizations such as:

- 👥 Total Number of Passengers
- ❤️ Survival Rate
- 👨‍🦱 Survival by Gender
- 🎫 Survival by Passenger Class
- 📈 Age Distribution
- 👨‍👩‍👧 Passenger Demographics
- 📊 Survived vs. Not Survived
- 🔍 Interactive filters for exploring the data

---

📂 Dataset

The project uses the Titanic passenger dataset, which contains information such as:

- Passenger ID
- Passenger Class
- Name
- Gender
- Age
- Number of Siblings/Spouses
- Number of Parents/Children
- Ticket
- Fare
- Cabin
- Port of Embarkation
- Survival Status

📈 Key Insights

The dashboard helps identify relationships between passenger characteristics and survival outcomes, including:

- Differences in survival rates between male and female passengers.
- Variation in survival across passenger classes.
- The relationship between passenger age and survival.
- Overall passenger survival and non-survival distribution.
